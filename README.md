# NutriScanAI

## Description
NutriScanAI is a tool for scanning and analyzing nutritional information from food labels using AI.

## Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/imswamya/NutriScanAI.git
    ```
2. Change to the project directory:
    ```bash
    cd NutriScanAI
    ```
3. Install the required dependencies:
    ```bash
    pip install -r requirements.txt
    ```

## APK Download
You can download the NutriScanAI Android APK from the following link:
[Download NutriScanAI APK](link-to-your-apk)

## Usage
1. Run the main script:
    ```bash
    python app.py
    ```
2. Read those comments to understand backend working

## Configuration
Before running the application, ensure you have replaced the placeholder API keys and project ID in the `.env` file with your own credentials:
- `FIREBASE_PRIVATE_KEY_PATH`
- `GOOGLE_API_KEY`
- `FIREBASE_PROJECT_ID`
